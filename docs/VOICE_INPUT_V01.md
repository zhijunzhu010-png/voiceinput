# Voice Input V0.1

1. 选择本地 Whisper 或云端 OpenRouter。本地需选择 whisper-cli.exe 和多语种模型；GPU 需使用对应 CUDA 引擎。
2. 云端填写自己的 OpenRouter API Key 与语音转写模型 ID，点击保存云端设置。Key 用 Windows 当前用户 DPAPI 加密，不写入日志。
3. 点击开始录音，讲话后再次点击结束；也可使用 Ctrl+Shift+F9。录音由用户主动结束。
4. 本地在电脑识别；云端会上传本次录音。识别后不会自动输入。
5. 编辑文字；若需重试，可切换识别方式或模型后点击重新识别，无需重新录音。重新识别成功会替换编辑内容。
6. 点击确认输入，在三秒内切换到目标应用并点击输入框。软件输入当前文字，不按 Enter；请检查目标应用实际结果。也可以复制后手动粘贴。

主界面可切换 English、简体中文和繁體中文，并可贴入 YouTube 或 B 站公开链接启动转写。识别设置、重新识别、确认输入和日志位于“更多选项”中。

当前录音在下一次录音或正常退出时删除。异常退出可能留下系统临时文件。没有自动硬件探测，CUDA 仍需自行配置。

自动测试采用模拟 HTTP 响应，不产生云端费用；真实 Key、账户余额及模型可用性需使用自己的账户实际验证。当前未提供独立的连接测试按钮。
