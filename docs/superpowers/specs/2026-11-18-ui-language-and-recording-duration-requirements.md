# VoiceInput 简洁版 UI 与录音需求总结

## 1. 背景

当前 VoiceInput 的界面文字硬编码为简体中文。用户希望通过界面语言下拉栏，在英文、简体中文和繁体中文之间切换，并让界面立即显示所选语言。

当前单次录音最长约两分钟，原因是主窗口在构造时创建了两分钟间隔的 `DispatcherTimer`，计时器到期后调用 `StopCapture()`。这是应用层的录音时长限制，不是 Whisper 模型或音频格式的固有限制。本需求明确移除该上限，录音不再因两分钟计时器自动停止。

## 2. 目标

- 提供一个界面语言下拉栏。
- 下拉栏提供三个选项：
  - English
  - 简体中文
  - 繁體中文
- 用户选择语言后，界面文字显示对应语言。
- 默认语言保持简体中文，以兼容现有用户体验。
- 保持“界面显示语言”和“语音识别语言”相互独立。
- 移除两分钟录音上限，避免录音被固定时长强制中断。

## 3. 非目标

- 本次不把语音识别语言扩展为“英文/简体中文/繁体中文”。现有“自动/中英混合、中文、英文”识别选项继续独立存在。
- 沿用本地 Whisper、OpenRouter、音频采集、视频转写和文本输入流程。
- 本次不要求翻译识别结果，只翻译应用界面文案。

## 4. 功能需求

### 4.1 界面语言选择

1. 在主界面增加“界面语言”下拉栏。
2. 下拉栏固定显示三个选项：`English`、`简体中文`、`繁體中文`。
3. 用户选择某个选项后，主窗口可见的界面文字切换为对应语言。
4. 语言切换至少覆盖：
   - 窗口标题和版本标题；
   - 功能说明、标签、按钮、复选框、下拉选项；
   - 状态提示、错误提示、录音和识别进度提示；
   - 结果区、日志、复制、保存和清空等操作提示；
   - 视频转写相关界面文字。
5. 语言切换不应清空或修改：
   - 当前录音状态；
   - 当前识别结果；
   - 已填写的 API Key、模型路径、引擎路径和链接；
   - 当前语音识别语言选择。
6. 首次启动默认使用简体中文。
7. 语言选择应保存到本地配置，后续启动时恢复上次选择；如果配置不存在或无效，则回退到简体中文。

### 4.2 录音时长

1. 移除当前两分钟 `DispatcherTimer` 自动停止逻辑。
2. 用户通过“结束录音”按钮或全局快捷键主动结束录音。
3. 录音状态文案不得再声称“最长 2 分钟”。
4. 本次不新增新的固定录音时长上限。
5. 如果未来需要防止无限录音，应另行设计可配置上限、磁盘空间保护和用户提示，不在本需求中隐式加入。

## 5. 交互流程

1. 用户打开应用，界面默认显示简体中文，或显示上次保存的界面语言。
2. 用户展开“界面语言”下拉栏。
3. 用户选择 English、简体中文或繁體中文。
4. 应用立即刷新界面文字，保留当前业务状态和用户输入。
5. 用户开始录音时，状态区域显示所选语言对应的录音提示，不显示“两分钟上限”。

## 6. 验收标准

- 下拉栏准确列出 English、简体中文、繁體中文三个选项。
- 分别选择三个选项后，主窗口主要文字均切换到对应语言，不出现明显混杂或缺失文案。
- 切换语言不会中断录音、清空识别结果或改变识别语言设置。
- 重启应用后，能够恢复上次选择的界面语言。
- 没有语言配置时，应用显示简体中文。
- 录音持续超过两分钟时不会被计时器自动停止。
- 用户主动结束录音后，仍能正常进入后续识别流程。

## 7. 简洁版 UI 需求

本需求以 Whisper 类工具的清晰、低干扰布局为参考，优先保证录音主流程易懂，减少用户需要判断和操作的按钮数量。

### 7.1 页面结构

主界面按以下层级组织：

1. 顶部品牌区域：显示 VoiceInput 名称和简短说明。
2. 界面语言下拉栏：提供 `English`、`简体中文`、`繁體中文`。
3. 主说明区域：用一句话说明“说话即可转成文字”。
4. 录音区域：使用一个明显的主按钮，在“开始录音”和“结束录音”之间切换。
5. 链接转写区：在录音区下方提供 YouTube 和 B 站公开链接输入框及转写按钮。转写时显示进度和取消按钮。
6. 识别结果区域：麦克风与链接转写共用可编辑的文本框，旁边保留“复制结果”和“清空”。
7. 更多选项：集中提供识别语言、本地及云端设置、重新识别、确认输入、保存 TXT 和识别日志。

### 7.2 按钮精简原则

- 主界面不放置与核心录音流程无关的高级配置按钮。
- 录音流程只使用一个主按钮完成开始/结束状态切换。
- 结果区直接显示复制和清空，其他结果操作在“更多选项”中。
- 引擎路径、模型、云端服务和识别语言在默认折叠的“更多选项”中。
- 验收时确认公开链接可从主界面启动转写，转写期间可查看进度和取消，成功后结果出现在共用编辑区。

### 7.3 设计稿

设计稿文件：[compact-voice-ui.html](../../../compact-voice-ui.html)

设计稿展示：

- Whisper 风格的简洁窗口布局；
- 顶部界面语言下拉栏；
- 一个圆形主录音按钮；
- 录音下方的公开链接转写入口；
- 一个识别结果编辑区；
- “复制结果”和“清空”两个辅助按钮。

## 8. 实现建议

推荐采用“资源字典/本地化资源 + 语言选择器”的方式集中管理三种语言文案，而不是在事件处理代码中逐个拼接条件字符串。界面语言状态应与 `RecognitionOptions.Language` 分开保存，避免改变界面语言时意外改变 Whisper 的识别语言。

录音流程应移除两分钟 `DispatcherTimer` 依赖；录音结束继续由用户操作触发。后续若增加安全上限，应使用独立、明确的配置和本地化提示。
