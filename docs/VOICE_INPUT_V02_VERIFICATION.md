# VoiceInput V0.2 验证记录

2026-11-19 · Windows x64 发布目标，在 Snapdragon X Windows 主机上验证。

| 验证项 | 结果 |
|---|---|
| .NET 8 Release 自包含发布 | 成功，ZIP 内确认包含应用、CPU Whisper、tiny 模型、yt-dlp、FFmpeg 和 OpenCC 许可证。 |
| MSTest 回归 | 21 项通过。覆盖已有链接规则、云端请求及界面语言，以及新增繁简保护、字幕优先、SRT 往返、推理排队和独立取消。 |
| WPF 切页 | 实例化主窗口后交替切换两个入口，确认语音草稿与链接输入均保留。 |
| 本地媒体 | 用真实 FFmpeg 和 Whisper 从短 MP3 生成带时间段结果，导出 SRT 后重新解析成功。 |
| 公开链接 | yt-dlp 成功读取一段约 10 分钟的公开视频元数据。该工具提示本机缺少可用的 JavaScript 运行时，部分 YouTube 格式可能缺失。 |

本轮改动包括左侧导航、独立任务和草稿、新配置的普通话与简体默认值、OpenCC 字形转换、各阶段计时、字幕优先路径、独立音轨与本地文件转写，以及 TXT/SRT 导出。UI 采用主窗口中的两个持久页面区域，媒体逻辑移入独立代码文件。

中文真实录音的旧版 CER／延迟对比、约 10 分钟及约 2 小时的完整媒体对照、B 站端到端、真实麦克风及云端设备验收、剪辑软件实际导入仍待执行。现有短样本结果仅用于功能验证。
